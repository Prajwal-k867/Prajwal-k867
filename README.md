### 🧠 [AI Personalized Learning System](https://github.com/Prajwal-k867/ai-personalized-learning-system)
> An AI-powered adaptive learning platform designed to eliminate one-size-fits-all education by creating tailored learning paths based on assessment performance.

- **Problem Solved:** Traditional learning platforms deliver static content to all learners regardless of existing knowledge or learning pace. This system evaluates individual baselines to target specific student weaknesses.
- **Key Features:**
  - **Diagnostic Assessments:** Subject-specific evaluations to establish knowledge benchmarks.
  - **Adaptive Learning Paths:** Dynamically generated study topics tailored to weak areas.
  - **Interactive Learning & Quizzes:** Topic-focused learning resources paired with practice quizzes.
  - **AI Performance Tracking:** Analytics dashboard monitoring progress and skill growth over time.
  - **Global Search:** Instant access across subjects, materials, quizzes, and learning path modules.
- **Tech Stack:** React.js, Flask / Node.js, Python, MongoDB
